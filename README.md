# Notes From a Passive-Aggressive Fridge

[![make.fun bounty](https://make.fun/bounty/u-motasimfuad-notes-from-a-passive-aggressive-fridge-83c00ad7)](https://make.fun/bounty/u-motasimfuad-notes-from-a-passive-aggressive-fridge-83c00ad7)

## The note

> I've logged 47 door openings today and zero actual meals. The light inside isn't a tourist attraction.

The fridge is smug about its sensors — it has been counting every door
opening — and petty about the owner's habit of standing there staring
without ever eating anything. The sting lands at the end: the light
inside the fridge is not a tourist attraction, so stop gawking at it.

## Run it

```sh
python3 main.py
```

This writes the note to `/output/entry.txt` — one line, 102 characters,
valid UTF-8 — and prints it to stdout.
